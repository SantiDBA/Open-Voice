# Font provenance

Both faces are self-hosted and committed. Nothing is fetched from a third party at runtime.

| File | Family | Source | License |
| --- | --- | --- | --- |
| `Archivo-400.woff2`, `Archivo-600.woff2` | Archivo | Omnibus-Type, via Google Fonts | SIL Open Font License 1.1 |
| `AzeretMono-400.woff2`, `AzeretMono-500.woff2` | Azeret Mono | Displaay, via Google Fonts | SIL Open Font License 1.1 |

Archivo carries the catalog numeral and the interface. Azeret Mono carries every number, which is
genuine measurement in this product and therefore earns the monospace rather than borrowing it as a
"technical" costume.
