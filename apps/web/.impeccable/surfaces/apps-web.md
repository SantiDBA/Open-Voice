# Surface brief — apps/web

## Scope and visitor mode

Operate. One surface: the browser client of Open Voice. The visitor completes a task, they do not
browse: they talk to a speaking agent. Everything below serves that task.

## Audience, job, action, proof

One person, at their own desk, every day, bilingual Spanish/English, already knows what the product
is. Job: start a hands-free conversation and keep control of it. Action: press one control, talk, and
interrupt when the answer is wrong. Proof available and real: the transcript, the live signal, and the
per-turn timings this project already instruments.

## Constraints carried from product truth

Only states the backend can actually produce are shown: idle, live, transcribing, thinking, speaking,
interrupted. No "acting" state, because no tool loop exists. No translation ghost anywhere: the
product does not translate. The language mark shows which voice is speaking, which is real. Text input
is always visible. Instrumentation stays available as a quiet layer, never a modal.

## Chosen direction and memorable moment

Fused challenger "Catálogo de fábrica", catalog id brand-identity-canon-saville-catalog-sleeve,
chosen by the user from a hand where it was catalogued competitive. The roll had assigned grounded
candidate 3, Intertítulos bilingües; the user chose the challenger, so the challenger is the build.

The memorable moment: the agent's voice is not a widget in a corner, it is the field. A hairline plot
drawn from the real signal owns the work area, and when you speak over the answer the current catalog
entry is struck with a red cut mark and stays struck, permanently, in the index.

## Direction contract

THESIS: The conversation is a factory catalog. Every turn gets a FAC number, the agent's presence is
one hairline plot that owns the field, and state is spoken in industrial color code instead of words.
It refuses the category default of chat bubbles with a round microphone button, and it refuses the
other default of a neon sci-fi HUD.

OWN-WORLD: matte black ground, hairline plot ink at one pixel, an industrial color code of blue,
yellow, red, bone and steel used as categorical marks rather than decoration, engraved caps with wide
tracking for system text, tabular monospace for every number. No corner radius anywhere. Vast
unprinted black. Exactly one plot owns the field at a time.

STORY: The visitor opens it and the agent's presence is the work area, not a control. Turns accumulate
as numbered entries they can walk back through. What the agent says is not a bubble: it is the entry
under the current number. When they talk over it, the entry is struck with a red cut mark and stays in
the catalog, because an interruption is a fact about the conversation, not an event to be deleted.

FIRST VIEWPORT: A left column holding a plain list of turn numbers, standard web list navigation, never
a costume. The center work area where the plot owns the field, full height, hairline radar grid with
the live trace. A right rail carrying the current entry's readout: the number set large, the color-code
strip, the language mark, and the turn timings as tabular numbers. Pinned to the bottom at all times,
the text composer and the two controls as ordinary bordered buttons, the live one carrying the red cut
block. Instrumentation rides as one quiet line inside the right rail.

FORM: Fused challenger "Catálogo de fábrica", catalog id
brand-identity-canon-saville-catalog-sleeve, user-chosen from a hand where it was catalogued
competitive against the assigned grounded direction. Concept seed key f22301c2, mode operate. Build
path code-led, no comp owed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the
verdict, DESIGN.md, and every shipping raster carrying its provenance

## Unresolved decisions

- Self-hosted faces still to be sourced and committed; the craft floor forbids a system face as the
  display voice, so the catalog numeral and the engraved system text need real files.
- The plot's data source: microphone amplitude while listening and playback amplitude while speaking
  are both available in the browser; which one owns the field during each state is a build decision
  that must not invent data.
- Color-code semantics are not yet assigned. The world says information is coded through color and
  number, so each state needs exactly one code, and the same code must never mean two things.
